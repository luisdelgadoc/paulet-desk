# Pollos Marios — Servicio al Cliente (datos ficticios de demo)

> Negocio ficticio usado para la demo. Ningún dato de esta página corresponde a un
> negocio real.

## Modelo
Cadena de pollo asado con 7 locales en 3 ciudades. Venta en local, para recoger y a
domicilio propio (sin apps de terceros). El pedido por WhatsApp queda en estado
**Pendiente** hasta que el local confirma precio final y tiempo de entrega.

## Tiempos
- Para recoger: 20–30 min desde que el local confirma.
- Domicilio: 35–50 min según zona y hora.
- Horario de atención: lunes a domingo, 11:00 a 21:30.

## Métodos de pago
- Efectivo (contraentrega o en el local)
- Transferencia (Nequi o Bancolombia; el local envía los datos al confirmar)
- Datáfono disponible solo para recoger en el local

No se cobra por adelantado desde el WhatsApp. El pago se coordina con el local al
confirmar el pedido.

## Preguntas frecuentes
**¿Hacen factura electrónica?** Sí, se solicita al confirmar el pedido con el local.

**¿Tienen opción sin ají / sin sal?** Sí, se puede pedir el pollo sin ají y con menos
sal; indícalo al registrar el pedido.

**¿El pollo es fresco o congelado?** Fresco, se asa por pedido en cada local.

**¿Reservan para grupos grandes?** Para pedidos de más de 4 pollos enteros conviene
avisar con 2 horas de anticipación para asegurar disponibilidad.

**¿Manejan domicilio a oficinas / eventos?** Sí, dentro de las zonas de cobertura de
cada local; para pedidos grandes fuera de zona se coordina caso por caso con el local.
